# LOGIN-05 — Login con credenciales incorrectas

**ID**: LOGIN-05

**Título**: Login con credenciales incorrectas

**Precondición**: Estar en la página de login

**Pasos**:

1. Ingresar usuario/password inexistentes
2. Click en Login

**Resultado esperado**:

- Muestra el error: "Username and password do not match any user in this service"

**Prioridad**: Alta
