# LOGIN-02 — Login con usuario bloqueado

**ID**: LOGIN-02

**Título**: Login con usuario bloqueado

**Pasos**:

1. Ingresar `locked_out_user` / `secret_sauce`
2. Click en Login

**Resultado esperado**:

- Muestra el mensaje: "Sorry, this user has been locked out"
