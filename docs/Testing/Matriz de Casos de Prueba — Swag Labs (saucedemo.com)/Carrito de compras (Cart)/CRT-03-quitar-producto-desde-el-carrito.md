# CRT-03 — Quitar producto desde el carrito

**ID**: CRT-03

**Título**: Quitar producto desde el carrito

**Precondición**: El carrito contiene al menos un producto

**Pasos**:

1. Presionar el botón "Remove" del producto deseado

**Resultado esperado**:

- El producto desaparece de la lista
- El badge del carrito se actualiza correctamente
- El total se recalcula

**Prioridad**: Alta
