# CRT-04 — Continuar comprando desde el carrito

**ID**: CRT-04

**Título**: Continuar comprando desde el carrito

**Precondición**: El carrito contiene uno o más productos

**Pasos**:

1. Hacer click en el botón "Continue Shopping"

**Resultado esperado**:

- El usuario regresa a la vista de catálogo de productos
- El estado del carrito se conserva
