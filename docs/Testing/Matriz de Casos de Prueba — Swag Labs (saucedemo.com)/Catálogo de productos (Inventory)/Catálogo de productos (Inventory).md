# Catálogo de productos (Inventory)

Esta página refleja los casos del catálogo de productos.

## Casos principales

- Visualizar listado completo de productos
- Ordenar productos por nombre A-Z
- Ordenar productos por nombre Z-A
- Ordenar productos por precio menor a mayor
- Ordenar productos por precio mayor a menor
- Agregar producto al carrito desde el listado
- Quitar producto del carrito desde el listado
- Ver detalle de un producto
- Volver al listado desde el detalle
- Verificar imágenes rotas con problem_user
