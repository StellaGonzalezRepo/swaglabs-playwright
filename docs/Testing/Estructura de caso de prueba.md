# Estructura de caso de prueba

Este documento sirve como referencia para crear casos de prueba siguiendo la misma estructura utilizada en Confluence.

## Objetivo

Estandarizar la creación de nuevos casos de prueba para automatización con Playwright + TypeScript.

## Plantilla recomendada

- ID
- Título
- Prioridad
- Tipo
- Precondiciones
- Datos de entrada
- Pasos
- Resultado esperado
- Selector sugerido

## Macro de plantilla

Se utiliza una macro de creación desde plantilla para generar los casos en Confluence con la misma estructura de trabajo.

## Referencia

La estructura se mantiene alineada con el contenido del espacio SauceDemo.
